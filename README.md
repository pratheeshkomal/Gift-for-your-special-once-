# Little Letter 💌

A free, mobile-first interactive surprise/letter generator.

## Features
- Relationship + occasion selection
- Custom receiver/sender names
- Custom letter
- 3 interactive questions
- Cute bear-inspired CSS artwork (no external sticker pack required)
- Animated reveal flow
- Shareable links
- QR code generation
- No account required
- No database required: the generated letter is encoded into the URL hash

## GitHub Pages
1. Upload `index.html`, `style.css`, and `app.js` to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/root`.
4. Save and open the Pages URL.

Because the letter data lives in the URL hash, GitHub Pages can host the whole app without a backend.

## Note
The current share links are convenient for personal messages but are not encrypted. Don't put passwords, private credentials, or highly sensitive information into a letter.
